#  Scientific Calculator

A **Scientific Calculator Web App** built using **React and Tailwind CSS**.  
This calculator can perform **basic arithmetic operations** and **scientific calculations** such as trigonometric functions, powers, and logarithms.

This project was built to practice **React concepts and UI styling using Tailwind CSS**.

---

##  Features

###  Basic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)

###  Scientific Functions
- sin()
- cos()
- tan()
- log()
- square root (√)
- power (x²)

-  Modern UI using Tailwind CSS  
-  Fast calculations using JavaScript  
-  Responsive design (works on different screen sizes)

---

##  Technologies Used

-  **React** – for building the user interface  
-  **Tailwind CSS** – for styling  
-  **JavaScript** – for calculator logic
